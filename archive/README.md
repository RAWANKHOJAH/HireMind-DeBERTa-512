# Archive: DeBERTa branches

`HireMind-Plan_deberta_branches.bundle` is a full git copy of the two DeBERTa working branches (`m7-deberta`, `m7-deberta-512`): the training workflows, the CPU and GPU scripts and their commit history. They were kept here so that no DeBERTa work stays in the team repository.

Restore with:

```
git clone HireMind-Plan_deberta_branches.bundle -b m7-deberta-512 deberta-branches
```
